# Elara Lite downloads

**Version 1.1.1**

Elara Lite is a free app of 40 short lessons on social enterprise, from Social Innovation Africa.

- No account needed.
- Works offline: after you install it, you do not need internet.
- The lesson narration uses an AI-generated voice.

This page only holds the download files. There is no source code here.

## Android phone

**Download the app:** https://github.com/Narkour/Elara-Lite-Downloads/releases/latest/download/elara-lite.apk (about 25 MB)

You need **Android 7.0 or newer**.

1. On your phone, open the download link above. Use Wi-Fi if you can; you only need data once.
2. When the download finishes, open the file **elara-lite.apk** (tap the download message, or find it in your Downloads folder).
3. If your phone asks, **allow installs from this source** (your browser or file manager), then go back.
4. Tap **Install**, then **Open**.

All lessons, recordings and worksheets are inside the app. If you already have Elara Lite, installing this file updates it and keeps your saved progress.

## Basic phones (no app)

**Download the audio pack:** https://github.com/Narkour/Elara-Lite-Downloads/releases/latest/download/elara-lite-audio-pack.zip (about 18 MB)

It holds the recordings of all 40 lessons as MP3 files, numbered in lesson order, with a lesson list and a short guide.

1. Unzip it on a computer or smartphone.
2. Copy the MP3 files to a memory card (for example into its Music folder), or send them one at a time by Bluetooth.
3. Play them on any phone that plays MP3 files.

Playback and transfer depend on the phone.

## iPhone

There is no iPhone app. Elara Lite has a web version for iPhones and other smartphones, and a link to it will be added here when it is published.

## Good to know

- Elara Lite does not collect your information, and it has no adverts or accounts.
- Not every phone has been tested.
