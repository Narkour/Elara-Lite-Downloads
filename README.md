# Elara Lite downloads

Elara Lite is a free app of short lessons on social enterprise, from Social Innovation Africa. No account is needed, and once it is installed it works without internet.

This page only holds the download files. There is no source code here.

## Android phone

1. On your phone, open this link: **https://github.com/Narkour/Elara-Lite-Downloads/releases/latest/download/elara-lite.apk**
2. When the download finishes, tap the file to open it.
3. If your phone asks, allow installing apps from this source (your browser or file manager). The wording depends on the phone.
4. Tap **Install**, then **Open**.

- You need Android 7.0 or newer.
- The download is about 25 MB. Use Wi-Fi if you can. You only need data once.
- All lessons, recordings and worksheets are inside the app, so it works with no internet after that.
- If you already have Elara Lite, installing this file updates it and keeps your saved progress.

## iPhone

There is no iPhone app. Elara Lite has a web version for iPhones and other smartphones, and a link to it will be added here when it is published.

## Basic phones (no app)

Download the **audio pack**: **https://github.com/Narkour/Elara-Lite-Downloads/releases/latest/download/elara-lite-audio-pack.zip** (about 18 MB).

It holds the recordings for all 40 lessons as MP3 files, numbered in lesson order, with a lesson list and a short guide.

1. Unzip it on a computer or smartphone.
2. Copy the MP3 files to a memory card (for example into its Music folder), or send them one at a time by Bluetooth.
3. Play them on any phone that plays MP3 files.

Playback and transfer depend on the phone. The narration uses an AI-generated voice.

## Good to know

- Elara Lite does not collect your information, and it has no adverts or accounts.
- Not every phone has been tested. Tested phones will be listed here.
